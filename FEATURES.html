Product Specification

Foodie — Feature Overview

A social PWA for food lovers. Track restaurants, log meals, rank dishes, and discover the best version of your favourite food across every place you've visited.

👤

Users & Social

Accounts

  • Register and log in
  • Display name, avatar, short bio
  • Spring Security — local accounts only

Friends

  • Search for other users
  • Send / accept / decline friend requests
  • View full friend list

Groups

  • Any user can create a group
  • Add friends as members
  • A user can belong to multiple groups
  • All members can contribute content
🍽️

Restaurants

Adding

  • Any group member can add a restaurant
  • Required: name, address
  • Optional: cuisine type, website, phone

Map Integration

  • Provider: Google Maps API
  • Not included in V1 — future feature
  • Will add address lookup, lat/lng storage, and map pin display

Ratings

  • Scale: 1 (terrible) – 10 (perfection)
  • Each member rates independently
  • Group sees aggregate average per category
  • Employees & Service
  • Audio & Music
  • General Vibes
  • Price for Quality
  • Location & Locale
📋

Visits & Food Logs

Logging a Visit

  • Date, attendees from the group, notes
  • Co-visits supported — group members join the same visit post
  • Each attending member submits their own ratings independently
  • Visit total score is an aggregate of all members' ratings
  • All ratings visible to every group member

Food Items

  • Log individual dishes per visit
  • Name, description, optional price
  • Assign a dish category (e.g. "Steak")
  • Scale: 1 (terrible) – 10 (perfection)
  • Taste
  • Presentation
  • Portion Quality
  • Value for Price

Images

  • One or more photos per dish
  • JPEG, PNG, WEBP supported
  • Option A: binary data in PostgreSQL
  • Option B: Railway bucket storage
  • Exact solution TBD
⭐

Wishlists

Group Wishlist

  • Any member can add a restaurant
  • Visible to all group members
  • Check off when visited — moves to visited list

Personal Wishlist

  • Private to the individual user
  • Same check-off mechanic
  • Can optionally share with a group later

Entry Format

  • Freeform name + optional address
  • Can link to an existing restaurant in the system
  • isCheckedOff status tracked per item
🥩

Similar Meals — Cross-Restaurant Comparison

Dish Category Grouping

  • Each food item gets a freeform dish category
  • Categories normalised to lowercase for matching
  • Auto-builds a ranked list per category
  • Spans all restaurants the user or group has visited

Comparison View

  • Shows all logged instances of a dish type
  • Restaurant, date, user, rating, photo thumbnail
  • Sorted by rating descending
  • Filterable by group or personal visits

Example

  • "Steaks" → Steak at Restaurant A: 8.5
  • "Steaks" → Steak at Restaurant B: 7.0
  • Instantly see your best steak in the city
🗂️

Domain Model

User
  • belongs to many Groups
  • has many FriendRequests
  • has a personal Wishlist
Group
  • has many Users (members)
  • has many Restaurants
  • has a group Wishlist
Restaurant
  • belongs to one or more Groups
  • has an Address (lat/lng)
  • has many Visits
  • has many RestaurantRatings
Visit
  • belongs to one Restaurant
  • logged by one User
  • has many FoodItems
FoodItem
  • belongs to one Visit
  • has a DishCategory
  • has a FoodRating
  • has many Images
WishlistItem
  • belongs to Group or User
  • optional Restaurant link
  • isCheckedOff boolean
DishCategory
  • aggregated view across FoodItems
  • matched by normalised name
